## 五段互动

1. **视角扇** —— 拖焦距 8–400mm，视角扇形开合（全画幅 43.27mm 对角线实算）
2. **透视滑块** —— 同一只邮筒的两张实拍（24mm 凑近 / 85mm 退远）：主体同大小、背景天差地别——「焦距不改变透视，距离才改变」
3. **景深台** —— 三个旋钮 + DOF 公式（f² 平方级影响），对数距离轴上的清晰带 + 超焦距 H 实算
4. **等效换算台** —— 四种画幅 × 焦距 × 光圈：视角/景深/面积三层换算一次算清
5. **镜头剖面** —— 内对焦镜组滑动、光圈叶片开合、防抖组反向补偿动画
